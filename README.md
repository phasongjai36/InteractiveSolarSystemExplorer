# InteractiveSolarSystemExplorer
โปรเจกต์ Interactive Solar System Explorer สร้างเสร็จแล้ว โดยระบบมีฟีเจอร์หลักคือการจำลองดาวเคราะห์ 8 ดวงโคจรรอบดวงอาทิตย์พร้อมเอฟเฟกต์เรืองแสง พื้นหลังดาว และวงโคจร ผู้ใช้สามารถโต้ตอบด้วยการคลิกเพื่อดูข้อมูลหรือ Hover เพื่อขยายขนาด พร้อมชุดควบคุมที่ครบครัน ได้แก่ Play/Pause, Reset, ปรับความเร็ว (Slider/Presets) และเลือกดูรายชื่อดาว นอกจากนี้ยังออก
